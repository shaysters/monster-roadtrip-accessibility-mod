# Changelog

## Unreleased

### Fixed
- Campfire seat names are read on controller focus too, not only when focus lands on the spot's button.
- The repeat key (G, or L3 on controller) replays the online code, so controller players can hear it again.

## 1.0.0 - 2026-10-30

### Added
- Standalone installer (MonsterRoadtripAccessibilityInstaller.exe). It installs BepInEx if needed, then the mod, and can update, repair, or uninstall.
- When you host an online match, the online code is read digit by digit. Press C in the lobby to hear it again.
- Campfire spots say who is sitting there and how many seats are free.

### Changed
- Speech goes through Prism instead of Tolk: screen readers, braille displays, or built-in Windows speech when no screen reader is running. The mod now talks without a screen reader too.
- The README's BepInEx instructions point to the 32-bit (x86) package, which the game needs.
